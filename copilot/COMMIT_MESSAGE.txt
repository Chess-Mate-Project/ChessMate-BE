# UUID 기반 고유 배치 작업 ID 구현

## 변경 사항

### 문제점
- Spring Batch의 `JobInstanceAlreadyCompleteException` 발생
- 동일한 JobParameters로 배치 재실행 불가
- 게임 데이터 중복 조회 및 스트릭 데이터 정합성 문제

### 해결 방안
- UUID를 JobParameters에 추가하여 매번 고유한 Job Instance 생성
- 배치 재실행 가능하도록 개선
- 중복 조회 문제 완전 제거

### 구현 내용

#### UserBatchServiceImpl.java
- `java.util.UUID` import 추가
- UUID 기반 `batchId` 생성: `UUID.randomUUID().toString()`
- JobParameters에 batchId 추가 (username, token, batchId, since)
- 로그에 batchId 포함하여 추적성 향상

### 기대 효과
✅ JobInstanceAlreadyCompleteException 완전 해결
✅ 배치 작업 재실행 정상 작동
✅ 게임 데이터 중복 조회 문제 해결
✅ 스트릭 데이터 정합성 보장
✅ 배치 ID 기반 로그 추적 가능

### 파일 변경 목록
